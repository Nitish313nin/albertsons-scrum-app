# Live deployment

This app is server-based. Opening `public/index.html` directly will show `Failed to fetch` because the API server is not running.

## Render
1. Put this folder in a GitHub repository.
2. In Render, create a Blueprint/Web Service from that repository.
3. Render will use `render.yaml` and `Dockerfile`.
4. Wait for deployment to become Live.
5. Open the generated HTTPS URL on every phone.
6. On first login, use **Set / Reset Owner Password** with:
   - Email: nitishkumar.nin@gmail.com
   - Your chosen password (8+ characters)
7. Then Login.

All phones must use the same HTTPS URL. Do not open the HTML file from WhatsApp.
